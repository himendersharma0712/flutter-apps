# 🎲 Dice Roller App

A simple dice roller app which simulates the rolling of a dice using image assets and random number generation. 

It also features a colorful gradient background for the homescreen.

## 📂 File Structure
    lib
        - gradient_container.dart
        - main.dart
        - roll_dice.dart
        - stylized_text.dart
